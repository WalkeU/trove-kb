Paste a reader token to browse, or the owner (approver) token to browse and decide on proposals.

  • The token is kept in this page's memory only (or in this tab's sessionStorage if you tick the box). Never in localStorage or a cookie.
  • The page locks itself after 30 minutes without activity.
  • Agent tokens are not accepted here.
  • Do not use the owner token in a browser that an AI agent or a browser extension you do not trust can control.
